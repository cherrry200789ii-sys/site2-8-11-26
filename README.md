# Александра Седенкова — новостройки Тюмени

Готовый статический сайт: HTML, CSS, JavaScript, локальные изображения и шрифты. Сборка не требуется.

## Размещение на хостинге

Скачайте репозиторий через Code → Download ZIP и распакуйте архив. Загрузите содержимое папки сайта в public_html: index.html, styles.css, app.js, privacy.html, consent.html и папку assets. Файл index.html должен находиться непосредственно в public_html, а не во вложенной папке репозитория. Существующие файлы сначала сохраните в резервную копию.

## Проверка локально

`npm run dev` — локальный сервер Python 3 на порту 3000. `npm run check` — проверка синтаксиса JavaScript.

## Закреплённые контакты и подбор

Шапка с телефоном, Telegram, MAX, ВКонтакте и кнопкой «Оставить заявку» остаётся видимой при прокрутке. Форма открывается в диалоге и проходит четыре шага: квартира и расположение, бюджет и сроки, способ покупки, контакты, выбор мессенджера и согласие. Калькулятор ипотеки считает аннуитетный платёж по введённым параметрам локально; ставка по умолчанию является примером, дополнительные банковские расходы не учтены.

## Автоматическая отправка заявок — требует подключения

Последний шаг формы собирает имя, телефон, выбор Telegram/MAX и согласие. Форма POST-ит JSON в api/lead.php; успех показывается только после подтверждения API. Без конфигурации обработчик возвращает 503. Кнопки контактов в шапке работают независимо.

На SpaceWeb нужен PHP с расширением cURL. Скопируйте deployment/sedenkova-leads.example.php в папку аккаунта НАД public_html как sedenkova-leads.php и заполните токен и chat_id каждого бота. Не загружайте заполненную конфигурацию в GitHub или public_html. Telegram: создать бота через @BotFather, начать с ним диалог аккаунтом получателя. MAX: создать бота через официальную платформу MAX; возможность зависит от доступа к платформе. Личные ссылки на профили не заменяют API ботов.

Загрузка: index.html, app.js, privacy.html, consent.html и папка api. Сначала настройте ботов и проверьте доставку. До этого действующий сайт можно оставить на предыдущем варианте. PHP-обработчик не сохраняет заявки в базу; при ошибке API он сообщает о неподтверждённой доставке.
