# Александра Седенкова — новостройки Тюмени

Лендинг с шестью ЖК, локальными изображениями и шрифтами, отзывами с 2ГИС, ипотечным калькулятором и пошаговой формой. Сборка не требуется. Галереи скрыты до выбора проекта; первыми открываются планировки квартир. Цены заполняются владельцем отдельно.

## Размещение

Содержимое сайта размещается непосредственно в public_html: index.html, styles.css, app.js, privacy.html, consent.html, assets/ и api/. Не помещайте сайт во вложенную папку репозитория. Перед заменой сохраните резервную копию.

## Заявки на почту

Последний шаг формы собирает имя, телефон и отдельное обязательное согласие. JavaScript отправляет JSON в api/lead.php. PHP проверяет поля и передаёт письмо через mail() на фиксированный адрес cherrry207@rambler.ru. Отправитель: no-reply@novostroyki-tyumen72.ru. Получатель и заголовки не берутся из пользовательского ввода. В письме имя, телефон и пожелания клиента. Базы заявок и журнала их содержимого обработчик не создаёт.

На хостинге должны работать PHP 7.1+ и почтовая служба для mail(). SMTP-пароли и токены ботов этому варианту не нужны. Старый файл sedenkova-leads.php вне public_html не читается. Telegram, MAX и ВКонтакте остаются ссылками для прямой связи.

Успешный ответ означает принятие письма почтовой службой, а не подтверждение доставки. После загрузки выполните реальную проверку получения в Rambler, включая «Спам». Если письмо не приходит, запросите у SpaceWeb проверку журнала исходящей почты, разрешённого адреса отправителя и SPF/DKIM домена. Не публикуйте пароли и токены.

## Обновление на почтовый вариант

Замените index.html, app.js, privacy.html, consent.html и api/lead.php. Обновите страницу без кеша и проверьте доставку тестовой заявки. Остальные файлы менять не требуется, если предыдущие изменения уже загружены.

## Локальная проверка

`npm run check` — проверка JavaScript. `npm run dev` — Python-сервер для просмотра страниц, без выполнения PHP. Для полного локального запуска нужен PHP: `php -S 127.0.0.1:3000`; доставка зависит от настройки почтовой службы. В документах описана фактическая отправка на email, согласие сохраняется локально в браузере. Серверного реестра согласий нет.
